# مكّة ماركت — Full UI Prototype (Flutter)

مشروع Flutter عربي RTL يحتوي على ثلاث واجهات أولية ضمن تطبيق واحد للتجربة:
1. واجهة العميل: تصفح المنتجات، البحث، السلة، وإرسال طلب تجريبي.
2. لوحة الإدارة: مؤشرات تجريبية، إدارة المنتجات والطلبات بصورة أولية.
3. واجهة المندوب: قائمة طلبات تجريبية وتحديث حالات التوصيل.

## التشغيل
- ثبّت Flutter SDK و Android Studio مع Android SDK.
- افتح المجلد في Android Studio أو VS Code.
- نفّذ:
  ```bash
  flutter create . --platforms=android
  flutter pub get
  flutter run
  ```
- لإنشاء APK:
  ```bash
  flutter build apk --release
  ```

## حدود هذه النسخة
هذه نسخة واجهات وتدفق عمل Prototype ببيانات تجريبية داخل التطبيق. لا تحتوي بعد على خادم أو قاعدة بيانات مشتركة، ولا مزود دفع، ولا خرائط/تتبع حي، ولا مصادقة حقيقية. الطلبات لا تُرسل إلى متجر فعلي ولا تصل للمندوبين خارج هذه النسخة.

## المطلوب قبل التشغيل التجاري
- Backend وAPI وقاعدة بيانات مركزية (مثلاً Laravel + PostgreSQL).
- تسجيل دخول وصلاحيات منفصلة للعميل والإدارة والمندوب.
- مخزون حقيقي مع حجز الكميات ومنع البيع الزائد.
- أسعار وباركود وصور فعلية لـ 1000 منتج.
- تحديد مناطق خدمة العجمي ورسوم التوصيل.
- ربط الخرائط والإشعارات وبوابة الدفع.
- اختبار أمني وتشغيلي وسياسات الخصوصية.
